Smart Attendance System

Overview
This Python project is a **Smart Attendance System** that automatically records student attendance. It can load students from a CSV file (`students.csv`) and randomly mark them as **Present** or **Absent**. The attendance is then saved in `attendance.csv`.

This project is ideal for demonstrating basic Python programming, file handling, and practical automation.

---

Features
Load students from CSV or user input,
Randomly mark attendance as Present or Absent,
Save attendance in a CSV file with details,
Fully interactive and easy to run,
Simple and easy-to-understand Python code.

---

How to Run

1. Make sure you have **Python installed** (version 3.x).  
2. Ensure your project folder contains:
   - `attendance_system.py`  
   - `students.csv` (sample input file)  
3. Open **VS Code terminal** or PowerShell in the project folder.  
4. Run the program:

```bash
python attendance_system.py
